## Формат вариантов отображения

HTML-прототип в `design/` проверяет сценарий локально на демонстрационных данных. Его возможности не означают, что те же функции уже работают в Flutter-расширении.

- [ ] Утвердить версионируемую схему `profile.json`: формат, идентификатор, версия, название, описание, подходящие домены и пути.
- [ ] Определить режимы: изменение CSS, преобразование элементов и собственная разметка.
- [ ] Определить `rules.json`: поиск содержимого, привязки к шаблону и поддерживаемые действия.
- [ ] Подготовить пример пакета для одного реального сайта.
- [ ] Хранить файлы и изображения превью локально; определить лимиты и поведение при заполнении хранилища.
- [ ] Проверять пути, размер распакованных данных, обязательные файлы и версию формата ZIP до применения.
- [ ] В первой версии принимать CSS, шаблоны без исполняемых скриптов, ресурсы и декларативные правила.
- [ ] Различать обновление того же варианта и создание отдельного варианта по идентификатору.
