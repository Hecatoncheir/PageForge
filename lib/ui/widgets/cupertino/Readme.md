# Переключатель Cupertino

Локальная копия `CupertinoSlidingSegmentedControl` из Flutter 3.47.9
(`packages/flutter/lib/src/cupertino/sliding_segmented_control.dart`).
Исходная лицензия BSD сохранена в `LICENSE`.

Изменения: имя `PageForgeSlidingSegmentedControl`, публичные импорты и параметр
`showThumbShadow`, отключающий тень и её тонкий контур в светлой теме.
Радиус фона увеличен до 14; радиус ползунка оставлен исходным (7).
Жесты, клавиатурное управление и анимации сохранены из Flutter.
При обновлении SDK нужно сверять копию с исходным компонентом.
