# Шрифты PageForge

Шрифты загружены из официального репозитория [Google Fonts](https://github.com/google/fonts). Файлы содержат латиницу и кириллицу; подключение через `fonts.css` не требует CDN.

| Файл | Источник | Доступная насыщенность |
| --- | --- | --- |
| `Nunito-Variable.ttf` | [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito) | 200–1000 |
| `NunitoSans-Variable.ttf` | [Nunito Sans](https://github.com/google/fonts/tree/main/ofl/nunitosans) | 200–1000 |
| `JetBrainsMono-Variable.ttf` | [JetBrains Mono](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono) | 100–800 |

Для каждого семейства сохранена отдельная лицензия SIL Open Font License 1.1 в файле `*-OFL.txt`. Бинарные файлы не изменены, только переименованы для удобного подключения.

Рекомендуемые роли: Nunito — название и заголовки; Nunito Sans — интерфейс и основной текст; JetBrains Mono — адрес сайта, версия и технические подписи.
