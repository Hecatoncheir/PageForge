# Дизайн PageForge

Три связанных прототипа без сборки и внешних ресурсов:

- `index.html` — одностраничный сайт с заголовком «Те же сайты. Другой взгляд.» и интерактивным примером интерфейса установленного расширения.
- `prototype.html` — интерфейс расширения с вкладками «Отображение» и «Разработка».
- `brand.html` — основной логотип «Мастерская», три альтернативы, цвета, шрифты и значки.

## Просмотр

Из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory design
```

Открыть `http://127.0.0.1:4173/`. Для локальных SVG-символов нужен HTTP-сервер: открытие HTML напрямую с диска может блокироваться браузером. Все шрифты и ресурсы входят в проект.

## Что можно проверить

На главной странице переключаются вкладки «Отображение / Разработка». Выбор карточки меняет оформление журнала позади панели; кнопка исходного отображения сбрасывает выбор. «Все» открывает демонстрационный общий список. Вкладки и варианты доступны с клавиатуры. Области ZIP в этой иллюстрации отключены: добавление и выгрузка работают в установленном расширении.

В общем списке видны превью и отметки «Выбрано / Не выбрано». «Читалка» показывает пример сохранённого выбора для другого сайта. Поле репозитория в демонстрации служит иллюстрацией; установка по ссылке работает в расширении.

Chrome и Firefox под основной кнопкой ведут к ZIP соответствующего браузера. При загрузке страницы ссылки обновляются по публичному списку релизов GitHub, включая предварительные выпуски с обоими пакетами. Если API недоступен, остаются прямые ссылки на выпуск 0.2.0.

В отдельном локальном прототипе работают выбор карточек, удаление и выгрузка ZIP. Во вкладке «Разработка» можно выгрузить выбранный вариант; после выбора исходного отображения — получить основу. Импорт принимает ZIP перетаскиванием или выбором файла. Пример скачивается по кнопке внизу страницы прототипа.

С публичного сайта нет ссылок на прототип и айдентику. Они сохраняются в репозитории для локальной разработки по прямым адресам `http://127.0.0.1:4173/prototype.html` и `http://127.0.0.1:4173/brand.html`. Команда `python tools/package-site.py` готовит папку `site-dist` только с главной страницей и нужными ресурсами. Workflow `Сайт` публикует её в GitHub Pages; локальные HTML-страницы в публикацию не попадают.

В пакете можно поменять `name`, `id`, `version` в `profile.json` и три цвета превью в `styles.css`: `--preview-bg`, `--preview-ink`, `--preview-accent`. Новый `id` добавляет карточку, существующий — обновляет её. Цвета превью извлекаются из CSS, поэтому новая карточка появляется автоматически. Для прототипа используются только адрес `journal.example`, четыре демонстрационных структуры и формат `schemaVersion: 1`.

Это проверка взаимодействий, а не механизм изменения реальных сайтов. Импортированные HTML/JS не выполняются; произвольный CSS не применяется к странице. Исходный ZIP при импорте целиком не сохраняется: текущий прототип хранит только сведения профиля и CSS и при выгрузке создаёт стандартную структуру пакета. Финальный формат и полноценное сохранение ресурсов будут реализованы в расширении.

Состояние сохраняется в `localStorage` этого прототипа. В импорт не передаются данные сторонним серверам. Можно хранить до 50 профилей; ZIP ограничен 8 МБ, суммарный распакованный размер — 16 МБ, CSS — 64 КБ.

## Визуальные правила

| Роль | Решение |
| --- | --- |
| Основной знак | «Мастерская»: пластичная форма, вырезанная P, оранжевая искра |
| Заголовки и название | Nunito, вес 900 |
| Интерфейс | Nunito Sans, вес 400–800 |
| Домены, версии и подписи | JetBrains Mono |
| Тёмная тема | `#282828`, `#32302f`, `#fbf1c7`, акцент `#fe8019` |
| Светлая тема | `#fbf1c7`, `#f2e5bc`, `#282828`, акцент `#af3a03` |
| Движение | Нажатия 180 мс, смена вкладок 240–260 мс, смена темы 280 мс |

Цвета основаны на [Gruvbox](https://github.com/morhetz/gruvbox). Предпочтение `prefers-reduced-motion` отключает заметные перемещения. На обычном экране ноутбука главная страница помещается по высоте; на телефоне и при большом масштабе допускается естественная прокрутка. Список вариантов внутри расширения прокручивается независимо.

## Ресурсы и перенос

`assets/logo.svg` — основной знак; `logo-stamp.svg` — его именованный оригинал. `logo-monogram.svg`, `logo-ligature.svg`, `logo-imprint.svg` — альтернативы. Буквы вырезаны из силуэтов, чтобы знак читался на обоих фонах. `app-icon.svg` и `extension/icons/` — готовые значки. `assets/icons.svg` — набор простых линейных символов. PNG основного знака доступны в оранжевом, графитовом и кремовом цветах.

Для обновления PNG, SVG-символов и иконок после изменения исходников:

```sh
node tools/generate-brand.mjs
```

Лицензии шрифтов находятся рядом с файлами в `assets/fonts`; лицензия fflate — в `assets/vendor`. При переносе во Flutter сохранять компоновку, цвета, размеры и поведение прототипа. Код импорта демонстрационных данных не заменяет полноценную реализацию ZIP-хранилища расширения.
