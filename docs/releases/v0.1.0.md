Первый предварительный выпуск PageForge — расширения для собственных оформлений сайтов.

### Возможности

- Компактный интерфейс Flutter, светлый и тёмный Gruvbox, плавный переключатель «Отображение / Разработка».
- Добавление ZIP перетаскиванием или выбором файла; CSS, собственные HTML-шаблоны и декларативные привязки.
- Карточки оформлений, автоматическая подготовка превью, сохранение выбора и возврат исходного вида.
- Кнопка «Все»: общий список установленных оформлений с доменами, удалением и выгрузкой.
- Выгрузка выбранного оформления либо стартовой основы сайта; имя файла по домену, например `github.com.zip`.
- Локальные шрифты и движок, хранение вариантов в браузере.

### Установка

**Chrome / Edge:** скачайте соответствующий `pageforge-*-0.1.0.zip`, распакуйте, включите режим разработчика в списке расширений и выберите «Загрузить распакованное расширение».

**Firefox 140+:** распакуйте `pageforge-firefox-0.1.0.zip`, откройте `about:debugging#/runtime/this-firefox` и выберите `manifest.json` через «Загрузить временное дополнение».

ZIP самого расширения нужно распаковать для установки. ZIP оформления добавляется внутрь PageForge.

### Примеры оформления

- `pageforge-theme-example-com-paper.zip` — «Бумага» для example.com.
- `pageforge-theme-example-com-layout.zip` — новая разметка example.com.
- `pageforge-theme-github-gruvbox-studio.zip` — тёмный Gruvbox для GitHub, с более выраженной переделкой главной страницы на широких экранах.

После установки расширения откройте соответствующий сайт, добавьте ZIP примера во вкладке «Разработка» и выберите его во вкладке «Отображение».

### Проверка и ограничения

Пользователь подтвердил основной цикл на GitHub в Chrome на Windows: выгрузка ZIP с правильным именем, изменение, импорт и применение оформления. Автоматические проверки охватывают Flutter, ZIP, упаковку, запуск в Chromium, общий список, сохранение выбора, восстановление после ошибки и интерактивный пример сайта.

Firefox-пакет не подписан и предназначен для временной установки до перезапуска браузера. Публикация в магазинах и подпись XPI ещё не настроены. Ручная проверка Edge и Firefox, разрешений, превью и доступности остаётся в TODO. Поведение сложных сайтов, фреймов и Shadow DOM не является универсальным.

Контрольные суммы всех ZIP приведены в `SHA256SUMS.txt`.
