PageForge 0.2.2 позволяет устанавливать обновления оформлений прямо из списка «Все» — без повторного ввода ссылки на репозиторий.

### Изменения

- После «Проверить обновления» у оформления с новой версией появляется кнопка «Обновить». Скачивается конкретный найденный релиз, а не текущая ветка репозитория.
- Проверяются сохранённый источник, идентификатор оформления, версия и содержимое пакета. Ошибки сети, повреждённый архив или несовпадение версии не заменяют установленный вариант.
- Выбор сайтов сохраняется, открытые подходящие страницы получают новые стили при наличии доступа. Превью создаётся заново на подходящей активной странице; для закрытого сайта подготовка откладывается.
- Список «Все» остаётся открытым. На время установки действия блокируются; после ошибки можно повторить попытку. Обновлять можно и оформления других сайтов.
- Поздний ответ не возвращает удалённое оформление и не перезаписывает вариант, заменённый в другом окне во время загрузки.

### Как обновить оформление

Откройте «Все» → «Проверить обновления» → «Обновить» у нужного оформления. При необходимости браузер запросит доступ к API и серверу архивов GitHub.

Если оформление добавлялось через ZIP, один раз добавьте его по ссылке на репозиторий, чтобы PageForge сохранил источник. Проверка и установка выполняются по кнопке; фонового обновления нет. Сам PageForge по-прежнему обновляется вручную из пакета.

### Установка PageForge 0.2.2

**Chrome / Edge:** скачайте `pageforge-chrome-0.2.2.zip` или `pageforge-edge-0.2.2.zip`, распакуйте и загрузите папку с `manifest.json` через режим разработчика. Для обновления замените файлы в прежней папке и нажмите ⟳ у расширения. Сохраните путь установки, чтобы сохранить локальные оформления и выбор сайтов.

**Firefox 140+:** распакуйте `pageforge-firefox-0.2.2.zip`, откройте `about:debugging#/runtime/this-firefox` и выберите `manifest.json` через «Загрузить временное дополнение». Пакет не подписан; временная установка действует до перезапуска браузера.

Также приложены три ZIP оформления: `pageforge-theme-github-gruvbox-studio.zip`, `pageforge-theme-example-com-paper.zip` и `pageforge-theme-example-com-layout.zip`. ZIP расширения распаковывается для установки в браузер; ZIP оформления добавляется внутрь PageForge. Контрольные суммы всех шести ZIP — в `SHA256SUMS.txt`.

### Проверки

Для изменений прошли форматирование и анализ Flutter, 27 Flutter-тестов, 39 проверок JavaScript и 4 проверки упаковки Python, сборка пакетов браузеров, проверка Firefox и HTML-прототипа. В Chromium проверен полный сценарий установки обновления по кнопке с применением новых стилей и сохранением выбора. Когнитивная сложность собственного Dart/JavaScript-кода остаётся в пределах 10. При подготовке выпуска проверки повторяются на исходниках тега.

Автоматическая проверка Chromium использует тестовую страницу с заранее выданными разрешениями. Ручная приёмка настоящего popup, системных запросов разрешений и Chrome/Edge/Firefox на реальных сайтах остаётся отдельной задачей. Это предварительный выпуск; подпись Firefox и публикация в магазинах ещё не настроены.
