PageForge 0.2.0 добавляет установку оформлений из GitHub и проверку новых релизов. В общем списке теперь видны превью и сохранённый выбор для всех сайтов.

### Изменения

- Во вкладке «Разработка» появилось поле «Репозиторий GitHub». Поддерживаются открытые репозитории, ссылки на ветку, коммит и конкретный релиз. У обычной ссылки загружается ветка по умолчанию.
- Оформления из репозиториев проходят проверку формата, ресурсов и размера. Служебные файлы и справочные снимки не импортируются, исполняемые ресурсы оформления отклоняются.
- В «Все» добавлена кнопка «Проверить обновления»: расширение сравнивает установленную версию с опубликованными релизами PageForge и оформлений из GitHub. При наличии новой версии появляется ссылка на выпуск. Проверка выполняется по кнопке; автоматической установки нет.
- В «Все» отображаются сохранённые превью, домены и отметки «Выбрано / Не выбрано», включая выбор для закрытых сайтов. Если снимка ещё нет, предлагается открыть соответствующий сайт.
- На сайте Chrome и Firefox стали ссылками на пакеты последнего опубликованного выпуска. Обновлены интерактивный пример и его общий список с превью.
- Добавлена сетевая проверка настоящего репозитория [PageForge-github.com](https://github.com/Hecatoncheir/PageForge-github.com) в CI.

### Установка и обновление

**Chrome / Edge:** скачайте `pageforge-chrome-0.2.0.zip` или `pageforge-edge-0.2.0.zip`, распакуйте и загрузите папку с `manifest.json` через режим разработчика браузера. Для обновления распакованной версии замените файлы в прежней папке и нажмите ⟳ у расширения — путь установки должен остаться прежним для сохранения данных.

**Firefox 140+:** распакуйте `pageforge-firefox-0.2.0.zip`, откройте `about:debugging#/runtime/this-firefox` и выберите `manifest.json` через «Загрузить временное дополнение». Пакет не подписан; временная установка действует до перезапуска браузера.

При установке оформления из GitHub браузер запрашивает доступ к API и серверу архивов GitHub. Доступ к оформляемому сайту выдаётся отдельно при выборе варианта. Учётные данные при загрузке не отправляются.

### Пример GitHub в тёмном Gruvbox

В «Разработка» вставьте:

```text
https://github.com/Hecatoncheir/PageForge-github.com
```

Затем откройте github.com и выберите «GitHub · Gruvbox Studio». Также приложены три ZIP оформления: `pageforge-theme-github-gruvbox-studio.zip`, `pageforge-theme-example-com-paper.zip` и `pageforge-theme-example-com-layout.zip`.

ZIP расширения распаковывается для установки в браузер. ZIP оформления добавляется внутрь PageForge.

### Проверки и ограничения

Автоматически проверены форматирование и анализ Flutter, 11 тестов интерфейса и состояния, 16 проверок формата, загрузок и репозиториев, 4 проверки упаковки, запуск и сценарии в Chromium, сайт на разных размерах экрана. Отдельная проверка Chromium в CI подтвердила скачивание из настоящего открытого репозитория и получение релизов через GitHub API.

В автоматической проверке Chromium доступ к тестовым адресам выдан заранее. Ручная приёмка новой версии в Chrome, Edge и Firefox, системных окон разрешений и подготовки превью остаётся отдельной задачей. Это предварительный выпуск; подпись Firefox и публикация в магазинах ещё не настроены. Поддерживаются открытые репозитории GitHub и числовые теги релизов `vX.Y.Z` / `X.Y.Z`; фонового расписания проверок нет.

Контрольные суммы всех шести ZIP приведены в `SHA256SUMS.txt`.
