GitHub · Gruvbox Studio

Откройте github.com и добавьте ZIP во вкладке «Разработка» PageForge.
Выберите «GitHub · Gruvbox Studio» во вкладке «Отображение».

На главной странице GitHub при ширине окна от 1280 px появляются отдельная
боковая панель, округлённая верхняя панель и просторные карточки ленты.
На других страницах применяются палитра, типографика, оформление блоков и кнопок.
На узких экранах сохраняется обычное расположение блоков.

Вариант использует только CSS. Исходные ссылки, формы и кнопки не заменяются.
Шрифты Nunito, Nunito Sans и JetBrains Mono включены локально вместе с OFL.
Если политика сайта ограничивает шрифты, используются системные шрифты.

Для отмены выберите «Исходное отображение».
